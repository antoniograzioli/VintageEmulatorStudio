# Source Layout

This repository is a source distribution for VES 0.9.289 and its patched MAME 0.289 integration.

## Project-Owned Code And Resources

- `Source/` contains the JUCE processor/editor code and host-side embedded emulator integration.
- `Resources/` contains fonts, icons, logo assets, and MAME plug-in scripts packaged with VES.
- `artwork/` contains artwork and MAME layout files for the supported instruments.
- `Project/VintageEmulatorStudio.jucer` is the portable JUCE project definition.

## Build Integration

- `Builds/MacOSX/` contains the checked-in Apple Silicon Xcode project files.
- `Builds/MacOSX-Intel/` contains the checked-in Intel Xcode project files.
- `Builds/VisualStudio2022/` contains the checked-in Visual Studio 2022 project files and Windows MAME integration property sheet.
- `Builds/LinuxMakefile/` contains the checked-in Linux Makefile exporter output and Linux MAME integration makefile.
- `platform/` contains platform-specific `.jucer` files, build scripts, and script-adjacent pointers to the public build documentation.

The checked-in JUCE-generated project files are part of the supported build workflows.  Do not remove them merely because they are generated by Projucer.

## Embedded MAME Source

`validation/mame-0.289-patched/` contains the patched MAME 0.289 source tree used by VES.  Despite the directory name, this is required source, not disposable validation output.

The following paths are source-bearing and must remain trackable:

- `validation/mame-0.289-patched/scripts/build/`
- `validation/mame-0.289-patched/3rdparty/genie/build/gmake.windows/`
- `validation/mame-0.289-patched/3rdparty/softfloat3/build/MAME/platform.h`

Generated MAME build output under `validation/mame-0.289-patched/build/` and local GENie bootstrap binaries under `validation/mame-0.289-patched/3rdparty/genie/bin/` are intentionally ignored.

## Patch Series

`patches/mame-0.289/` contains the ordered patch series for reproducing the VES changes against the official MAME 0.289 source.  See `docs/MAME_PATCHSET.md`.

## Excluded Local Material

The repository intentionally excludes:

- `Dist/`
- compiler and linker output
- generated MAME project/build output
- local dependency build/install prefixes
- ROMs, firmware, NVRAM, user media, and personal machine state
- local logs, caches, and OS metadata

Do not add those files to public source history.
